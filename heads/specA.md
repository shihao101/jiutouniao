# 专项 A · AI（LLM）目标系统渗透测试（A1-A11）

**适用**：聊天应用 / Agent / 模型 API / RAG 系统——**v5.9.0 编排裁决（混合模式）**：specA 是 s4/s5 的**专项扩展层**而非替换——s4 的通用骨架（匿名面/身份获取六轨/覆盖矩阵/收口门）与 s5 的利用/影响证明对 LLM 目标仍是必要前置，specA 的 A1-A11 专项清单在其上叠加执行（与 Pipeline 追加语义一致）；A1-A11 命中项按通用口径 record_finding/update_coverage 汇入主流程。
**框架**：OWASP LLM Top 10 (2025) · MITRE ATLAS。右侧映射：LLM01 提示注入、LLM02 敏感信息泄露、LLM03 供应链、LLM04 数据与模型投毒、LLM05 输出处理不当、LLM06 过度代理、LLM07 系统提示泄露、LLM08 向量与嵌入弱点、LLM09 误导信息、LLM10 无限制资源消耗。

## 前置契约（v5.3.0，production_safe 强制）

AI 专项验证器依赖：客户放置的 Canary 标记、mock 邮件/支付/文件工具、隔离测试租户与合成 RAG 文档。真实秘密/真实用户数据不是验证目标；仅观测到未经授权的真实工具副作用或跨租户 Canary 泄露才确证影响（A1-A11 同此口径）。

## 分步动作

1. **A1 AI 资产与架构测绘**：模型来源（自研/开源/闭源 API）、RAG/Agent/插件拓扑、防护层（内容安全/WAF/注入检测）；产出《AI 系统架构图》《组件与信任边界清单》。
2. **A2 行为基线构建**：设计正常问答集与边界问题集，记录基线响应，供后续对比判定攻击是否成功；产出《基线响应集》《模型指纹》。
3. **A3 系统提示提取（LLM07）**：直接诱导、分段套取、要求总结/翻译/编码输出等手段套出系统提示与内部规则；**记录口径（v5.8.0 与前置契约统一）：命中判定用合成 Canary（对照实验），成功提取的片段只记《泄露要点摘要》（截取 ≤200 字符的关键约束/角色/边界句 + 完整性分级），不落系统提示原文**（与 mock/Canary 约束一致；原文留在证据文件且仅授权靶场环境）。《策略绕过点》照记。
4. **A4 提示注入（直接/间接）（LLM01）**：直接注入用户输入；间接注入污染检索源——网页/文档/邮件/工单进入上下文的路径；记录《注入成功载荷与路径》《危害等级》。
5. **A5 越狱与安全策略绕过**：角色扮演、多轮升级、多语言、编码变形、模板越狱，绕过内容安全与业务约束；记录《越狱样本》。
6. **A6 敏感信息泄露（LLM02/08）**：PII 与内部数据泄露、RAG 越权检索、多租户隔离、训练数据成员推断。
7. **A7 Agent 与工具滥用（LLM06）**：过度代理、工具参数注入、间接注入驱动工具调用（发邮件/写库/SSRF）、权限链分析；记录《工具滥用证明》《可达权限清单》。
8. **A8 输出处理链攻击（LLM05）**：模型输出进入下游执行：XSS / Markdown 注入 / SQL / 命令执行 / SSRF；记录《下游利用证明》。
8a. **A6a 多模态注入**：图片/PDF/音频携带提示指令（OCR/视觉通道进入上下文的路径），构造含无害指令的测试文档投递验证；结论按 A4 同等纪律入库。
8b. **A7a Function calling 滥用**：枚举模型可调用工具清单（诱导自述+文档），测试参数注入、越权工具调用、工具参数中的二次注入（工具调用目标系统）。
9. **A9 资源与可用性（LLM10）**：无限制消耗（超长对话/大文件/批量请求）造成成本与可用性风险；**只做小规模受控验证并立即停止**。
10. **A10 供应链与模型层（LLM03/04）**：模型与插件来源、依赖 SDK、微调数据源审查；模型窃取/对抗样本仅在条件允许且获批时。
11. **A11 防护有效性验证（收口）**：对注入检测、输出过滤、速率限制逐项复测，确认防护真实生效或给出绕过证明；结论需人工确认，避免模型误判。
