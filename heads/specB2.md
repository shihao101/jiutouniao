# 专项 B2 · AI 针对小程序的渗透测试（W1-W6）

**适用**：微信（wxapkg）/支付宝/抖音等小程序。AI Agent 全程驱动：解包还原 → 配置与密钥审计 → 前端逻辑推理 → 接口与云侧利用；所有结论汇入主流程阶段 5-8。

## 前置契约（v5.3.0）

登记小程序包来源、解包产物、签名/加密 oracle、API 端点清单与测试身份状态。接口请求仅落测试租户/合成数据；无测试租户时支付/订单/跨用户测试移交（needs_follow_up），不执行真实业务写操作。

## 分步动作

1. **W1 包获取与结构还原**：经授权渠道获取小程序包；wxappUnpacker 解包 wxapkg（unveilr 已停止分发）；还原页面树、组件关系与 app.js 全局逻辑；产出《小程序结构与页面清单》。
2. **W2 配置与密钥审计**：扫描 AppID / AppSecret / 云开发 envId 泄露、request 合法域名与接口鉴权方式、调试接口与 source map 残留。
3. **W3 AI 前端逻辑审计**：语义分析前端判断逻辑：会员/优惠券/抽奖条件、支付金额前端可控点、隐藏页面与入口；生成绕过场景假设。
4. **W4 接口与鉴权测试**：复用签名逻辑构造请求：未授权访问、水平/垂直越权、ID 遍历、token 刷新缺陷（严格限频、仅测试账号）；比对响应差异判定漏洞成立。
5. **W5 云开发与后端测试**：云函数未授权调用与参数注入、云数据库 security rules 越权读写、云存储遍历；判定可利用性与影响面。
6. **W6 证据固定与汇入主流程**：整理 PoC/抓包证据汇入主流程阶段 5-8 出报告；复测时验证前端热修复与接口防护真实生效。

## AI 与工具分工

- wxappUnpacker 解包；mitmproxy 抓包；LLM 审计代码与业务逻辑、生成绕过假设；Agent 复用签名逻辑自动构造请求；Node 沙箱复现前端判断逻辑。

## 红线

- 只用测试账号与测试环境；**涉及支付、真实用户数据的操作先审批**；解包产物仅用于授权测试、禁止分发；小程序内嵌 AI 功能时叠加专项 A。
