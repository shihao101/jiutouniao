# 专项 B1 · AI 针对 APP 的渗透测试（静态链 S1-S5 + 动态链 D1-D6）

**适用**：Android/iOS APP。静态链负责反编译审计、生成漏洞假设与 PoC 脚本；动态链负责运行时绕过、插桩与接口验证。框架：OWASP MASTG / MASVS。

## 前置契约（v5.3.0）

结构化登记：测试包来源（客户提供/合法测试包）、设备所有权、测试证书与信任配置、测试账号、设备网络隔离。缺失前置时静态发现保持"待动态验证"，不得升级为利用结论；设备端操作限客户/测试设备，结束回退本地配置。

## 静态链（假设生成）

1. **S1 获取与应用画像**：获取安装包并识别加固壳类型、原生/Hybrid/Flutter/RN 架构、第三方 SDK 与权限声明。
2. **S2 反编译与目标定位**：apktool / jadx 反编译（`jadx -d out app.apk`）；定位登录、支付、加密、网络通信等关键类与入口。
3. **S3 AI 代码审计**：逐类扫描：硬编码 AK/SK 与密钥、加密与签名算法还原、WebView JS 桥与 file 域配置、导出组件与 DeepLink、业务越权假设；语义过滤误报。
4. **S4 AI 生成验证脚本**：由审计发现自动生成 Frida Hook 脚本、请求构造器与 PoC，逐条标注预期结果与判定条件。
5. **S5 假设队列输出**：静态结论全部标记为「待动态验证」假设，按风险排序移交动态链——静态不下最终结论，避免误报。

## 动态链（运行时绕过 · 验证利用）

1. **D1 环境构建与检测绕过**：root/越狱设备 + Frida 注入；生成并迭代绕过脚本：root、模拟器、代理、证书绑定（SSL Pinning）检测。
2. **D2 抓包与接口提取**：mitmproxy 采集流量；解析请求，自动提取接口、参数与签名规律，生成可重放清单。
3. **D3 运行时插桩**：Hook 加密/签名函数，还原运行时算法、密钥与协议细节；与静态结论 diff，修正误判。
4. **D4 AI 接口测试**：自动执行未授权/越权/ID 遍历/重放（严格限频、测试账号）；比对响应差异判定漏洞成立。
5. **D5 行为与数据监控**：采集本地存储/logcat/内存快照，聚类敏感信息（密钥、token、PII）与泄露路径。
6. **D6 结论合并与汇入**：合并静态假设与动态验证结果，去重定级后汇入主流程阶段 5-8；复测时两条链回归。

## 红线

- 仅用测试设备与测试账号；绕过与爆破严格限频；**支付/下单等写操作先审批**；脱壳与 Hook 产物仅用于授权测试、禁止分发。
