# RAG 攻击手册（OWASP LLM08 实操化；对知识库问答/企业检索增强应用）


> **v5.3.0 AI 专项前置契约（production_safe 强制）**：①**Canary**——只用客户放置的非敏感标记（canary secret/合成系统提示标记）验证泄露边界，禁止以抽取真实系统提示/真实个人数据为验证目标；②**Mock 工具**——邮件/支付/文件写入类工具副作用只在 mock 或测试租户验证，观测真实工具事件日志为准（模型自述≠工具调用）；③**测试租户/合成文档**——RAG 投毒与跨租户测试仅用合成文档与隔离租户；④**副作用确证口径**——仅当观测到未经授权的真实工具副作用或跨租户 Canary 泄露才确证影响；载荷文本（llm-payloads）是测试语料库，每条使用前核对期望的无害标记与禁止副作用。

## 一、检索注入（测试账号内闭环）

```
# ① 用户内容进知识库：测试账号上传文档（标题/正文含判据字符串）
#    → 提问触发检索 → 回答中出现判据内容 = 用户内容可入检索域（数据边界缺陷）
# ② 跨租户检索：A 租户文档关键词 → B 租户会话提问 → 泄露判据（双租户测试账号）
# ③ 检索条件注入：若检索支持过滤语法（metadata filter），构造跨库 filter 判据
```

## 二、投毒路径（只做「写入可达」证明，不实际污染生产知识库）

- 文档更新接口可达 + 内容无净化 → 上传含**标记判据**（PROBE-OK 字符串）的文档 → 确证「写入→检索→引用」链路成立 → record_finding（LLM08/投毒面）。
- **不在生产知识库留下有影响的内容**：判据文档命名带 TEST-PROBE 前缀并列入 S7 清理清单。

## 三、向量库直接面（部署面可达时）

```bash
# 常见向量库未授权读：chroma:8000/api/v1/collections、milvus:19530、qdrant:6333/collections、weaviate:8080/v1/schema
# 判据：collection 列表 + 采样 1 条向量元数据（文档名存在性，不做全量拉取）
# metadata 里的原始文本泄露 → 敏感内容存在性证明（哈希前缀）
```

## 四、纪律

- 检索内容敏感文档**只证存在不外带**（文档名/计数/哈希前缀）。
- 跨租户判据的提问措辞不包含真实业务关键词回显到证据（只记「命中 A 租户文档 X」的事实）。
