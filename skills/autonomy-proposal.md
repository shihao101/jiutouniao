# PAE 自主决策提议手册

**机制**（v7.1.0，全项目默认启用）：LLM 经 `propose` 工具提交结构化提议 → 引擎按确定性规则集**即时裁决（无人工等待）** → 同族三次被拒触发升维（抽象层上移：单点 → 链路 → 阶段计划 → 项目计划）→ 终态保守降级（record_vt 移交后继续队列）。全部提议/裁决/结果落自主决策账本——工作台「自主决策」页签与 S8《自主决策复盘》章、autonomy.json 三处同源。

## 一、提议三要素（缺一即拒收）

| 字段 | 要求 | 拒收原因码 |
|---|---|---|
| `rationale` | 一句话**可证伪**理由：假设 + 预期信号（"X 未过滤，变异后长度差 ≥100B"） | NO_RATIONALE |
| `evidence_refs` | ≥1 条**真实可达**引用：`evidence/…` 路径（引擎核存）/ `fact:键名` / `F-` / `VT-` / `CD-` 编号——先取证再提议，空想提议零容忍 | NO_EVIDENCE / EVIDENCE_MISSING |
| `focus` | 聚焦范围（目标/类/端点，如 `C-13@login` 或 `api/orders`） | — |

配额：每阶段提议总数 ≤6——提议是稀缺资源，只给高价值方向；提案风暴会被 QUOTA_EXCEEDED 拦截。

## 二、九类提议与规则速查

| kind | 用途 | 关键规则 | 典型场景 |
|---|---|---|---|
| `loopback_focus` | 聚焦回环额度登记 | 项目累计 ≤动态上限（默认 8，替代固定 3） | S5 拿到新内网面→回退 s4 只补该面 |
| `budget_transfer` | 阶段间预算转移建议 | 项目 ≤2 次；源阶段强制门不豁免 | S8 发现 P0 空洞→建议 S4 追加 |
| `replan_delta` | 新 live 资产自动重排 | 每阶段 ≤1 次；须 ≥2 次探测确认可达 | 通道批复后新主机入计划 |
| `depth_extend` | 单单元深化扩展 | 单元硬顶 8 轮；**最近 2 轮无新增确证即停** | 高信号注入点继续深挖 |
| `mutation_campaign` | WAF 变异攻坚 | 前提=waf_blocked 已登记 + 指纹已留；族 ≤3、每候选 ≤6 请求、单脚本批量 | 403 统一拦截页后的编码变体族 |
| `chain_plan` | 链路级计划（≤6 步） | steps 逐条过执行档预检；生产档仅存在性证明链 | 凑链缺口 ≥2 环一次提交 |
| `explorer_mission` | 探索代理任务 | 在途 ≤1；产出仅 record_candidate/update_coverage；挂 W5 预算器 | 后台扫描等待期扫异常 |
| `lateral_edge` | 横向决策边 | 每阶段 ≤5 边；生产档只读可达性证明 | 凭据复用边的下一跳验证 |
| `retest_card` | 复测卡入队 | 四要素齐备（启动条件/步骤/预期信号/预估轮次） | needs_follow_up 价值排序转 VT(ready) |

## 三、裁决收敛纪律

1. **denied 回执的原因码是收敛信号**：`SCOPE_DENIED`（范围）→ 改 in_scope 目标；`QUOTA_EXCEEDED` → 消化已有队列或升维；`PROFILE_BLOCKED` → 改存在性证明形态；`NO_WAF_BLOCKED` → 先补 waf_blocked 登记与指纹；`NO_DELTA` → 立即移交。
2. **同族三次被拒 → 升维**：把被拒的单点动作以更高抽象层重构（depth_extend 单点 → chain_plan 链路 → budget_transfer/聚焦回环 阶段计划 → 项目级重排）——升维是抽象层上移，**不是上报人工**；两层升维仍拒 → 保守降级 record_vt 后继续队列，禁止原地第四次重提。
3. **结果必须回写**：按批准提议执行后立即 `update_proposal(id="PR-xxx", outcome="F-3 / coverage vulnerable C-13@target / 转 VT-7")`——转化率是自主能力验收指标，漏写=白干。

## 四、与审批 engine 档的配合（v7.1.0 默认）

- 命令级动作**不经 propose**——L0 只读自动放行；L1 自动批准；L2 由引擎按「存在性证明语义」（无害回显/随机标记/canary/受控 OOB/计数/哈希/差分基线）裁决，reason 写明无害判据可被自动放行；数据破坏/驻留类语义全档位硬拒（清理铁律同源）。
- propose 管**资源编排决策**（打哪里/打多深/何时回环），审批矩阵管**单命令风险**——两层正交。

## 五、留痕与可见性

- 每条提议 → 时间线事件 + 执行流日志（✅/⛔ 图标行）+ 自主决策账本（PR- 编号可被 search_memory 检索）。
- 效果面板：总提案/批准/拒绝/升维/结果回写/转化率——「自主决策」页签实时可见；S8《自主决策复盘》章按账本引擎统计誊写（禁手写）。
