# PHP 类型混淆（Type Juggling）

**进入条件**：PHP 目标 + 密钥/口令比较走 `==`/`!=` 松散比较、或比较函数参数类型可控。

## 一、版本判据（先判 PHP 版本再选 payload）

PHP 8 起 `'php'==0` 为 **false**、`md5([])` 抛 TypeError（经典 `[]` 技巧失效）→ PHP7 及以下才适用的招式需要版本证据（X-Powered-By/报错指纹）。

## 二、0e 魔法哈希（md5/SHA1 松散比较绕过）

`md5` 对：`240610708` ↔ `QNKCDZO`——**成立条件是两串摘要各自匹配 `^0e\d+$`（科学计数法都为 0），不要求摘要字符串相同**：240610708 的 md5=`0e4620...`、QNKCDZO 的 md5=`0e8304...`，两者 `==` 成立（原正文曾误写"摘要相同"，已并回勘误）；`sha1` 对：`10932435112` ↔ `aaroZmOk`（同规则，各自以 0e 开头）。用法：找回/比较接口提交两值其一使哈希 `==` 匹配。判据：比较逻辑用 `==`。

## 三、比较函数变体

`strcmp($secret,$input)==0` → 传数组 `?p[]=1`（PHP8 报 TypeError 但 7 返回 0=相等）；`json_decode` 后 `{"password":true}` 与任意字符串 `==` 成立；`intval("0x1A",0)` 十六进制转换；**HMAC 松散比较**：`hash_hmac(...) != '0'` → 构造 data 使输出匹配 `^0e\d+$`（同 0e 魔法）。

## 四、决策树

1. 确认比较点（登录/找回/签名校验/token 比对）；2. 看 PHP 版本；3. `==` → 0e 魔法/true/数组三选一按参数类型；4. `strcmp` → 数组；5. 均不中 → ruled_out 附版本与比较类型证据。

## 五、纪律

0e 对/true 注入均为**只读验证**（登录成功即停，不做后续操作并立即登出）；命中后 record_finding（CWE-694）+ 建议修复改 `===`/`hash_equals`。

### 真值表关键行与勘误

- **勘误**：0e 魔法哈希成立条件是**两串摘要各自匹配 `^0e\d+$`**（科学计数法都为 0），**不要求摘要字符串相同**——240610708 的 md5=`0e4620...`、QNKCDZO 的=`0e8304...`，两者 `==` 成立
- `'0010e2' == '1e3'` → true（按 float 1000.0 比较，**不是 0**——高频误区）；`'' == 0 == false == NULL` 相邻链全 true；`'0' == false`（唯一非空串对 false 成立）；`'123a' == 123` 截断
- intval 补：`?id=010`（base 0 八进制→8）；`?id=1e2`（e 截断，需 `intval((float)"1e2")`=100）
- NULL 魔法：`@sha1($_GET['x']) == @sha1($_GET['y'])` 双方报错折叠 NULL → NULL==NULL；白盒找 `@` 抑制符
- 首发包清单：`password[]=x`、`password=`、`0`、`true`、`admin%00`
