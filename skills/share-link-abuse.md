# 分享面安全专项（"无凭据直达业务数据"的第一候选面——链接即凭证）

> 定位：分享面把「鉴权」变成「持链接即可达」——一旦链接可预测/可篡改/不可吊销，就是**无凭据直达业务数据**的
> 最短路径。实战原型：患者影像系统 bundle 还原出 share 面参数（sid/rid/keyId/sign/expires + allowShared/
> allowDownload/allowForward 权限位）后，分享面成为攻击树根目标的最短路径候选。
> 触发：bundle/页面出现 share/sign/expires/keyId/token 分享语义，或存在"分享/二维码/导出链接"功能。

## 一、分享机制还原（离线先行，零目标流量）

```bash
# bundle 里还原分享链接构造（intel-factory 承接）
grep -oE 'share[^;]{0,120}|Signature[^;]{0,60}|Expires[^;]{0,60}|keyId[^;]{0,60}' evidence/s2_js/*.js | head -20
# 权限位语义：allowShared/allowDownload/allowForward 是客户端位还是服务端强制（第三节 T6 裁决）
# 签名算法候选：md5/sha1(对象ID+盐) / HMAC(keyId) / 时间戳截断 —— crypto-offensive 还原
```

产出：分享链接模板 `?sid=&rid=&sign=&expires=&keyId=` 各参数语义表。

## 二、测试矩阵（自有对象先行，他人对象只测门控）

| T | 测试项 | 步骤 | 确证判据 | 判定 |
|---|---|---|---|---|
| T1 | **链接熵值** | 为**自有对象**生成 N≥10 条分享链接 → 样本差分（长度/字符集/时间相关性/自增） | 可预测（短随机/自增/纯时间戳）→ 可枚举他人分享 | 中-高（CWE-330） |
| T2 | **改参越权** | 自有分享链接改 sid/rid/keyId 为相邻值 | 改参后返回他人对象数据 = 分享面对象级越权（IDOR 分享形态） | 高（CWE-639）——api-idor 联动 |
| T3 | **过期绕过** | 自有链接 expires 改未来时间 | 改参后仍可用 = **签名未覆盖 expires**（离线即可篡改）；已过期链接仍可用 = 服务端不校验 | 中-高（CWE-613） |
| T4 | **签名伪造** | 签名算法还原（crypto-offensive）→ 离线伪造**自有对象**的新签名/新 expires | 自造签名服务端认 = 签名机制可伪造 | 高（CWE-347） |
| T5 | **吊销缺失** | 撤销/删除自有分享 → 旧链接复放 | 撤销后仍可达 = 分享不可吊销 | 中（CWE-613） |
| T6 | **权限位强制** | 服务端视角验证 allowDownload/allowForward：客户端隐藏下载按钮，直接拼 download 接口 | 前端隐藏但服务端放行 = 权限位仅前端 | 中（前端权限依赖，A04） |
| T7 | **未列分享/扩散面** | 分享链接 robots/noindex/索引面；链接非受控扩散（转发后无成员/次数限制） | 无过期+无次数限制 = 链接永续外发 | 中（信息级-中） |
| T8 | **匿名直达** | 分享链接退出登录态访问 | 匿名可得业务数据 = 分享面是 authz-diff 匿名矩阵的**天然阳性对照** | 按 authz-diff 口径记 |

## 三、判读纪律（ROE 硬约束）

1. **伪造/生成只针对自有测试对象**：T4 伪造签名后仅访问自有 sid/rid 验证"签名认了"；**他人对象一律只改参观察 401/403 门控形态，不消费返回数据**（T2 的确证=门控缺失形态差异，不等于下载他人报告）；
2. 分享链接**不复投**给真实用户/外部渠道（对外发布属 S5 审批面）；
3. T1 熵值不足是"概率级证据"，确证"可枚举"还需 T2 改参实测门控——两类证据分开登记；
4. 三态：缺陷确认=record_finding；门控有效（改参 401/签名含全部参数）=negative_valid；机制无法还原（黑盒签名不可见）=needs_follow_up 附已还原参数清单。

## 四、产出对接

- record_finding（cwe=CWE-639/613/347/330）+ update_coverage(vuln_class=分享面，notes 记 `share_tested/total`，T1-T8 逐项)；
- 攻击树衔接：分享面确证缺陷 → 攻击树"直接未授权访问报告数据"路径闭环；T8 命中 → **匿名攻击面与分享面合并定性**（S8 影响评估：无凭据直达数据路径）；
- 移交口径：签名算法不可还原时，把已还原参数语义表移交客户核实（ Salt 管理面）。

## v4.8 M6 工具通道兼容性声明

- 第一节离线还原**零目标流量**；T1-T8 为限速单请求（sleep 1s），curl 可全程执行；
- 二维码分享面（/App/cfilm/qrcode 类）参数探针：capability-primitive-search 定性"分享生成"是否匿名可达原语，链接生成后回本技能 T1-T8。
