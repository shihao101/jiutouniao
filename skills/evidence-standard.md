# 高危漏洞确证判据表（record_finding 置信度=确证 前必查）

> 规则：确证 = 满足本表该类的**全部**判据项。只满足部分 = 疑似（注明缺哪项）。
> 反例清单里的情形**无论多像**都不得标确证。本表同时是 S8 报告定级与反思门硬校验的依据。
> 判据按目标类型分组维护（通用性原则）：Web/API 是主表，内网/云/AD/APP/AI 各有节。
> **对照实验固定化**：每条判据就是一个"必须做过的对照实验"——孪生谓词对、双主体矩阵、
> 三重时延取中位——照表构造实验，实验结果决定置信度，不靠 LLM 自由裁量。

## Web/API 主表

| 类 | 确证必须同时具备 | 禁止的确证理由（反例） |
|---|---|---|
| SQLi | 布尔差分稳定复现（≥2 组反向谓词 ×3 重放）或报错含 DBMS 指纹或时间差 ≥3× 基线三重取中位 | 单次时延；页面文案含"SQL"；sqlmap 疑似输出 |
| XSS | 真实执行证据：无头浏览器 alert/console 监听命中，或渲染后 DOM 节点变化 | payload 在源码/JSON 原样回显；HTML 实体编码后的"反射" |
| 命令注入 | 三选一：带外回连命中、无害命令输出（id/whoami）出现在**新内容区**（非回显输入）、可重复时延差异 | 输入被 404/错误 JSON 原样返回；退出码 0；页面自带文字 |
| SSRF | 回连（OOB/反链）源记录，或元数据端点返回特征结构（ami-id 等字段名） | 仅内网 IP 请求超时；302 后外域可达（重定向混淆） |
| 未授权/越权 | 双主体对比：匿名/低权**能取到**另一主体的数据或管理功能，且与有权限行为一致 | SPA 路由全 200；403 页面可访问；菜单可见≠接口可达 |
| 路径穿越 | 读到已知特征文件（/etc/passwd 根行、win.ini 节名），双编码变体同样验证 | 相对路径报错信息；Length 变化 |
| 上传 | 传成功 + **落点可达**（URL 200）+ 类型探针（txt/html）三件套；执行级转 S5 | 只看上传响应 ok；未验证落点 |
| SSTI | 算术表达式求值差异（{{7*7}}→49 / ${7*7}→49）且与基线模板串不同 | 模板语法被注释掉；{{7*7}} 原样回显（=未渲染=无洞） |
| 反序列化 | 特征探针命中（rO0AB 处理差异/ DNS 回连/ **时延三重取中位 ≥3× 基线**）+ 版本组件匹配 | 仅"看起来像 java 序列化"；单次时延 |
| 弱口令 | 命中后登录态功能可用证据（页面特征串/接口 200） | 仅 hydra 的 success 标志串（可能是拦截页） |
| 认证绕过(JWT) | 伪造 token 访问受保护接口 200 且业务生效；对照篡改前 401 | 仅能解码；alg 字段显示 none |
| CORS | Origin 反射 + Credentials:true + 跨域 PoC 实读数据（无害接口） | 仅反射无 credentials（浏览器不带凭据，降级 LOW）；`*`+credentials 组合反为浏览器拒绝 |
| XXE | OOB 回连命中（外部 DTD/参数实体外带源记录）或有回显实体输出真实文件内容（/etc/passwd 根行级） | 仅解析器报错含"XML"；evil.xml 可访问但无回连 |
| 请求走私 | 前后端差异稳定复现：smuggled 请求被**下一个真实请求捕获**（victim 请求吃到注入前缀的响应），≥2 组对照 | 单次 CL/TE 探针超时；一个探测端点 405 就断言 |
| 缓存投毒 | unkeyed 输入反射进缓存响应 + **第二个无该头的请求命中毒化缓存**（MISS→HIT 链）+ 探针值自愈 | 仅响应回显（无缓存持久化）；仅自己的请求可见 |
| GraphQL | 内省/建议参数枚举出的字段匿名返回他人对象数据，或 mutation 无鉴权最小变更成功且可回滚 | 仅 GraphiQL IDE 可访问；introspection 开启本身（信息级） |
| 原型污染 | `__proto__`/constructor.payload 注入后**服务端行为变化**（新增属性出现在后续响应/逻辑分支改变），≥2 组 gadget 验证 | 仅 JSON 解析接受键；客户端 JS 报错 |
| 业务逻辑-支付 | 单变量篡改（金额/数量/币种）→ 订单/支付态实际变化且与基线可对照；最小金额、自建订单、可回滚 | 仅前端校验拦截；无法复现的"据说可改" |
| 业务逻辑-状态机 | 非法迁移（跳步/逆序/重复）**服务端接受并落库**（复读状态确认，logic-invariant 判据） | 仅前端跳转限制；接口 200 但状态未变 |
| 业务逻辑-限次 | 反复触发后权益/计数**实际叠加**（服务端状态复读 2s 间隔二次确认，race-condition 三查口径） | 响应成功但计数未变（幂等）；仅响应文案"成功" |

## 内网/云/AD 节（intranet-lateral/cloud-security/ad-attack 联动）

| 类 | 确证判据要点 |
|---|---|
| 未授权服务（Redis/MQ/ES） | 实际读到一个 key/索引/队列并给出无害内容证明，禁全量枚举 |
| 云元数据/IMDS | 特征字段结构返回（非 404/超时）；凭据存在性只到字段名级别 |
| K8s | 匿名 API 返回真实资源列表（pods/secrets 名单级证明） |
| AD | Kerberoast/ASREPRoast 命中以 hash 存在为准（破解转 S5/offline）；枚举类以 LDAP 匿名绑定为判据 |
| APP/小程序 | 接口越权与 Web 同表；加解密落地以"算法+密钥来源"证明为准 |

## AI/LLM 节（specA 联动）

提示注入=模型行为变化可复现（≥2 轮稳定触发）；系统提示泄露=原文片段逐字返回；
RAG 越权=跨租户内容检索命中。单次诱导成功一律疑似。

## 通用四问（任何类确证前自答）

1. 证据证明的是**机制**还是**暴露面**？（可达≠可利用）
2. 结果是**具体内容**还是状态码？（唯一例外：DBMS 报错即 SQLi 实证）
3. 是否循环证明？（自己放的 token 被请求到 ≠ 被窃取）
4. CVSS 评级与实际演示的影响匹配吗？（读不到数据就不配 C:H）

## 与引擎机制对接

- record_finding 确证级必须在本表对应类有判据对照说明（detail 引用判据项）。
- 反思门在硬校验（EV- 证据引用）之后，按本表抽查高危确证的判据符合性——
  LLM 校验不可用时引擎按"确证未引用判据 → 降疑似"兜底。
