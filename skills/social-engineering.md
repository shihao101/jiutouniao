# 受控社工演练

**授权红队专用**：仅当授权书明确列出人员演练范围/渠道/时段时启用。这是"人的流程测试"完整剧本（phishing-infra 只覆盖基础设施能力，本手册覆盖演练全流程）。安全边界：不收集真实敏感数据、不危害参与人、可随时熔断。

## 前置硬门（缺一即不做）

1. ROE 明确：演练对象部门/人数上限、渠道（邮件/SMS/电话/现场）、时段、禁止事项。
2. **隔离基建**：钓鱼域名/邮件服务器按 phishing-infra 部署（独立于测试目标域）。
3. 应急约定：员工举报/误操作的立即停止口径 + 客户安全团队实时联络人。

## 步骤

1. **目标画像**：公开信息画像（osint-leak-intel 联动：LinkedIn/官网组织架构/邮箱格式推导）——只取公开数据，不深挖个人隐私。
2. **场景设计**：三档强度按 ROE 选择——①通用钓鱼页（凭据收集页， Canary 标记）②定向伪造内部流程页（样式还原）③附件载荷（受控 beacon，Lab 域回连）。
3. **投递**：邮件渠道（phishing-infra 发信）——投递清单逐人登记；**发送量/频次硬限**（如单日 ≤N 人，防业务影响）。
4. **命中面评估**：凭据收集页命中数 = 统计口径（凭据**不记录明文**——只记录命中率与 Canary 触发，输入即哈希比对不落盘）；beacon 上线数与执行动作边界（仅存在性证明）。
5. **现场进入**（ROE 允许时）：尾随/工牌克隆（联动 wifi-nearfield 门禁节）——现场动作逐项审批 + 全程录像留证。
6. **报告口径**：命中率/渠道有效性/改进建议；**绝不输出个体员工名单**（除非 ROE 要求且客户书面确认）——对"人"的发现只输出统计与部门分布。

## 判据与记账

- 命中成立：Canary 触发/凭据哈希命中/beacon 上线（时间戳+渠道留证）。
- 演练全程 record_timeline（投递→命中→处置）；凭据收集页明文输入直接哈希处理——与凭据仓库掩码纪律一致。

## 工具探针

`which gophish sendmail; docker ps`——phishing-infra 已有基建节；gophish 缺失 install_tool 或模板邮件手工（SMTP 直连）降级，VT 注明。

## Execution Profile 标注（v5.3.2）

- **Lab Only**：beacon 载荷/凭据收集页部署——仅 isolated_lab 或授权书明确列出的演练窗口；
- **production_safe**：只做画像与基础设施就绪检查；
- 一键熔断语义：演练相关全部基建即时下线；收集数据按授权约定时限销毁（销毁留证）。

## 关联技能

phishing-infra（基建）、osint-leak-intel（画像）、wifi-nearfield（现场门禁）、observable-degradation（授权不含人员演练时的降级口径）。
