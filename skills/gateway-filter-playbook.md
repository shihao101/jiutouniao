# 网关过滤器架构目标剧本（v4.6 A1，承 某网关过滤目标 实证打法）

适用：统一 token 鉴权网关（未带 token 一律 401 JSON）+ 精确路径白名单。

## 一、差分扫描器（Authz-Diff 手工版）

1. 基线分类：已知 anon 端点（/sys/login、/captcha）作**阳性对照**；
2. 批量无 token GET 全部端点（含随机乱码路径作阴性对照——网关通配 200 时以体长/体内容为判据）；
3. **「500 未知异常」=可能穿透到控制器**的候选信号（v5.3.0 口径：500 仅是 Observation 候选——错误参数/业务异常/统一异常处理同样返回 500，不构成鉴权缺失确证）；确证须再加阳性/阴性对照与受保护资源差异三件套；批量脚本把 500 与 200 同列为候选并保留响应体片段；
4. 命中端点做同族复查（家族 4 端点）→ 确认遗漏为单端点还是族级。

## 二、写端点纪律

- GET 证据 ≠ POST 可用：写端点「未授权可达」成立，但「写效果」按 exploitability=conditional 呈现，
  CVSS 双轨（已证实影响基线分 + 条件上限分）——引擎 E4 对 untested 高危自动降级，实测后 update_finding 回写；
- 零副作用绑定层探测（空数组/类型错误）优先于真实参数构造。

## 二a、读端点量化三件套（v5.1：未授权读类命中的标准影响量化口径）

1. **量级证明**：count/分页参数差分证明可达规模（如 `total=10w` 响应字段、page=1/2/9999 的记录计数）——**只取计数不导出数据**（database-postex 批量导出禁令同源）；
2. **单条样本**：取 1 条记录做哈希前缀/字段名清单/截断截图（存在性证明口径，敏感字段掩码）；
3. **可达性边界**：说明匿名可达的对象范围（全部用户/仅本人注册段/多租户边界），写入 finding detail 供 CVSS 与 S8 定级；
4. 写端点命中后的最小状态变更验证（自建对象、L2+ROE、单次触发即停）参照本节第二节 conditional 双轨，实测后 update_finding 回写。

## v4.8 M6 工具通道兼容性声明

> 口径（loop-core v4.8 纪律 3）：先 probe 后 batch——每个外部工具对目标首次使用前先用小样本探针确认可用性，探针被拦/挂起先切适配通道再批量；探针结果写入交付物工具声明小节。各工具在「挑战型 WAF / 封闭站」下的可用性与适配通道：

- curl：低频手工请求始终可用——也是挑战态复放的最小工具（channel-snapshot 快照 cookie/UA 复放）；禁用它做大批量枚举。
- channel-snapshot.py：适配通道本体（挑战态提取/复放）——挑战型 WAF/封闭站下始终可用，且是本清单其它工具的适配通道来源。
