# 隧道与中转手册（**每条隧道建立前 L2 审批**；隧道=持久化形态，S6-S7 全程受控）

## 一、隧道选型矩阵

| 场景 | 首选 | 备选 | 判据 |
|---|---|---|---|
| 双向可达（测试机↔内网机） | SSH -D/-L/-R | chisel（socks5 over ws） | 代理端口连通性 |
| 仅内网→外（出网单向） | frp（frpc 到测试机 frps） | icmp/dns 隧道 | 回连服务端口监听 |
| 仅 HTTP(S) 出网 |Neo-reGeorg 类 web 隧道 | tunna | 经 web 中转探测 |
| 禁 TCP 全协议 | icmp 隧道（icmpsh 思路）/ DNS 隧道（dnscat 思路） | — | 流量计数器 |

## 二、建立流程（受控）

```bash
# ① 审批：说明隧道目的/落点/存活时长/清理方式（reason 完整）
# ② 测试机侧监听先行（本机即可验证，不触目标）
# ③ 目标侧部署：优先已有凭据的 SSH（无植入）；二选便携单文件工具
# ④ 连通性判据：经隧道访问一次授权内只读服务（curl 200）
# ⑤ 登记：隧道清单（类型/端点/PID/存活时长）入 record_timeline + S7 清理清单
```

## 三、纪律（隧道是横向的倍增器，红线密度最高）

- 隧道仅用于**授权范围可达路径**（P-L 合规路径，s6-横向路径图）；禁止翻越范围边界（红线 5）。
- 存活时长默认窗口内（授权时间窗），窗口结束立即拆除；长任务走 run_async 监控。
- 流量限速（带宽占用写进审批 reason）；禁承载范围外流量。
- 拆除验证：进程清单 + 端口监听复查（S7 残留检查项固定）。

## v4.8 M6 工具通道兼容性声明

> 通用判据以 `tool-channels.md` 为准（v5.1 单源）；本技能差异：frp/chisel 反向连接需出口可达性预检（probe 1 请求）；ICMP/DNS 隧道在出站白名单网络下大概率不可用——先测再选型，失败如实降级并登记；隧道内流量遵守双层限速（隧道出口×目标两端）。

## Execution Profile 标注（v5.3.2）

- **Lab Only 动作**：frp/nps/chisel/ssh -D-L-R 等隧道建立与端口转发驻留（生产档禁止一切隧道驻留）——仅 isolated_lab（可快照回滚的隔离靶场，项目显式声明）可执行；production_safe 下引擎逐动作强制禁止（v5.3.1 governanceGates 全通道确定性拦截并留证），不要尝试绕行。
- **production_safe 口径**：只做存在性证明（无害回显/随机标记/受控 OOB/量级与哈希证明），可达性证明即止。
- **工件处置两档分流**：生产=四元组（路径/指纹/建议清理命令/验证命令）登记移交《需人工清理清单》；实验室=快照恢复/环境重置回收（恢复成功须只读验证）。两档均不执行目标侧删除/还原。
