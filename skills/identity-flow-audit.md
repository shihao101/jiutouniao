# 身份流程全链审计手册（C-01 登录 / C-02 验证码 / C-03 重置 / C-04 第三方登录 / C-06 注册 / C-05 会话边界）

> 触发条件：任何登录/注册/找回/验证码面。定位：**auth-flow-deep 的流程细分手册**——每条链给出请求级探针与阴阳判据；登录入口拆分与弱口令面见 weak-cred-bruteforce，身份获取路线总纲见 identity-bootstrapping。

## 〇、纪律（全链适用）

- 每子项 ≤10 请求；**不爆破**（连续无效 ≤5 次即止，超限是 WAF/锁定行为不是测试目标）；
- 验证码**人机协同**：可取码定性（见下）但 OCR 自动打码仅在 ROE 允许且 captcha-ocr 可用时；exit 42 → request_user_input；
- 不注册（identity.auto_register=deny）：注册面只评估不提交真实注册；
- 证据：每条链落 `evidence/s4/identity-<flow>.tsv`（变体×响应码×差分关键词）。

## 一、验证码四问（C-02）

| 问 | 探针 | 阳性判据 |
|---|---|---|
| 签发可批量？ | 连续 GET 验证码端点 ×8（≤1 req/s），记尺寸/位数/Set-Cookie/限速头 | 无速率限制+无一次性消耗 → "匿名可批量取码"（低危确证，参照 GetCaptchaImg 形态） |
| 一次一用？ | 取码 A → 提交错值 → 再提交**同一码 A**（错误路径重放） | 旧码仍被接受=重放候选（需会话内无害验证） |
| 绑定会话？ | A 会话取码，B 会话提交 | 跨会话通过=绑定缺失 |
| 服务端真校验？ | 提交空码/错码（合法流程内） | 通过=硬缺陷；拒绝=阴性 |

- OCR 门槛：仅当上述成立且 ROE 允许，走 browser-auth L4（captcha-ocr.py 取码→识别→**立即单会话提交**，跨会话复用=假阴性）。

## 二、密码重置五问（C-03）

1. **token 熵**：从自己邮箱/响应取 token，`len≥32 且非时间戳/自增/邮箱哈希` 为阴性；短/可预测 → 确证候选；
2. **步骤跳跃**：不持 token 直接请求**最后一步**（new-password 页/接口） | 200+可设新密码=致命；
3. **用户枚举**：重置请求对存在/不存在账号的响应差分（文案/时延/状态码）→ 枚举 oracle；
4. **Host 头投递**：重置请求带 `X-Forwarded-Host: evil.test`（ Own 控收件时）→ 重置链接指向攻击域=高危；
5. **重放**：同一 token 完成重置后**再次使用** | 二次生效=一次性缺失。

## 三、第三方登录六问（C-04）

- `state` 缺失/固定/可预测（CSRF-login）；`code` 重放（同一 code 换 token ×2）；`redirect_uri` 宽松（任意子域/路径被接受）；token 换取页对**攻击者提供的 code** 直接消费；绑定接口未验证已有会话（账号缝合劫持候选）；
- 探针统一形态：走真实 redirect 流程一次抓基线，再单变量变异；判据=登录态落在攻击者可控上下文/跨账号缝合。

## 四、注册三问（C-06）

- 默认角色是否客户端可控（注册体 role/type 字段变异）→ 结合 authz-diff 验证该角色能力面；
- 已存在账号重复注册的响应差分（枚举 oracle 副产品）；
- 注册字段注入落点（用户名直接进 `X-Frame`/日志/管理面展示 → 存储型候选，转 xss-context 裁决）。

## 五、锁定与枚举（C-01）

- 连续无效 ≤5 次：观察**锁定提示文案/状态码/时延差分**（用户枚举 oracle）；
- 锁定边界：锁定按 cookie/会话/IP/账号哪个维度——清 cookie 重试、换 UA 重试各 1 次（参照 NMFR-InvitationLockToken 形态：**按客户端 cookie 计=清 cookie 绕过候选**）；
- 无锁定+无验证码 → record_finding（认证爆破可行性，CWE-307，配 oracle 差分表）。

## 六、会话边界（C-05）

- 建立/注销差分：注销后**旧会话 token 重放**（服务端未失效=会话未吊销）；
- 固定：登录前持有匿名会话 cookie，登录后**是否换新值**（未换=固定候选）；
- 属性基线接 http-security-headers（Secure/SameSite）。

## 七、产出纪律

- 每问 = 一个覆盖单元（update_coverage 引用 C-xx；Notes 记变体数与阴阳）；
- 无凭据项（登录后才能观察的）→ deferred 附启动条件；注册面结论只做评估不注册；
- 确证 findings 按 weak-cred-bruteforce / logic-sms-otp-matrix 的定级口径合并，避免同链重复条目。
