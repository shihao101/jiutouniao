# 实战案例（脱敏）：某教育行业 IOP 物联网教学平台 · 黑盒无凭证

> 脱敏口径：目标域名/IP/单位名一律泛化；证据文件名保留编号形态；本记录供对外能力说明引用。
> 任务标识：JT-58F32969F2（内部编号，不含敏感信息）；平台版本 v5.1.2/v5.1.3 运行。

## 任务参数
- 模式：黑盒、无凭证（auth_info 空）、strict_scope=true（仅主目标，Web 全部路径）
- ROE：禁止破坏性写入/持久化/DoS/批量下载；生产数据只做存在性证明
- 审批策略：auto_approve=all（用户选择）；46+ 个 L1 审批全部自动批准并留痕

## 流程与耗时（约 2 小时 15 分，26.1M tokens / 425 轮）
S1 PASS（范围边界表+接管指纹检查）→ S2 quality-pending（反思门 LLM 网络失败 3 连败，确定性门放行）→ S3 PASS（27 行筛查矩阵+测试计划）→ S4 预算代收口（120 轮耗尽，V3 清单代填）→ S5 PASS（利用验证+身份索取闭环超时移交）→ S6 代收口（零流量推演模式——无立足点）→ S7 三振出局降级门（零自建数据举证）→ S8 报告（369 行）

## 发现（5 项）
1. 中危·确证：登录端点缺失服务端暴力破解防护（无锁定/无频控/验证码不强制——10 次受控验证+时延序列证据，exploitability=verified）
2. 低·确证【清单外】：TLSv1.0/1.1 启用且 TLSv1.3 未启用（sslscan 独立窗口）
3. 低·确证【清单外】：生产环境 isdev=true 暴露未压缩前端源码与完整 API 情报
4. 低·确证：登录页缺失安全响应头（HSTS/XFO/CSP/XCTO）
5. 低·疑似【清单外】：auto-login gourl 参数无白名单透传（条件性认证后开放重定向）
